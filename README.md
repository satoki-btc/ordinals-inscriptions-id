# Sub100K Bitcoin Ordinals Inscriptions

A list of notable Bitcoin Ordinals inscriptions with inscription IDs #`0` #`99999`.

> Early Ordinals inscriptions are historically significant because they were among the first artifacts inscribed on Bitcoin after the Ordinals protocol launched in December 2022 by Casey Rodarmor.

---

## About

This repository tracks:

- sub-100k inscriptions ids
- Early inscriptions
- Historical artifacts
- Community-known grails
- Experimental inscription formats
